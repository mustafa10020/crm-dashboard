طريقة النشر

هذا النظام يعمل 100% بدون خادم (Serverless). بياناتك تُحفظ محلياً في متصفحك باستخدام LocalStorage، لذلك يمكن نشره مجاناً على GitHub Pages أو Netlify أو Vercel.

  • 1. ارفع هذه الملفات إلى مستودع GitHub جديد.
  • 2. من Settings ← Pages ← اختر الفرع main وحدد /root ثم Save.
  • 3. خلال دقائق سيظهر موقعك على رابط يشبه: https://اسمك.github.io/crm-dashboard/
