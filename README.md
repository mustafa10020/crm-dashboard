# Nexus CRM

نظام إدارة عملاء (CRM) احترافي، جاهز للرفع على **GitHub Pages** مباشرة بدون أي سيرفر أو دومين — الملفات كلها HTML + CSS + JavaScript فقط.

## المميزات
- **تسجيل دخول بصلاحيات**: مدير (Admin) يشوف كل حاجة، وموظف يشوف عملاءه بس.
- **لوحة قيادة (Dashboard)**: 12 مؤشر أداء (KPI) لحظي، رسمين بيانيين (توزيع الحالات + أداء الموظفين)، وحلقة "نبض الفريق" لأنشطة اليوم.
- **إدارة العملاء (Leads)**: إضافة / تعديل / حذف، بحث وفلترة بالحالة والموظف.
- **ملف عميل تفصيلي**: بيانات العميل، سجل أنشطة ومتابعات (Timeline)، وسجل محادثة بنمط واتساب لتوثيق كل تواصل مع العميل من الأول للآخر.
- **لوحة إدمن**: إدارة الموظفين (إضافة/حذف)، رسم بياني لأداء كل موظف، وتصدير/استيراد نسخة احتياطية من البيانات (JSON).

```

├── index.html      # كل الصفحات (Login + Dashboard + Leads + Customer + Admin)
├── css/style.css   # التصميم بالكامل
├── js/data.js       # طبقة البيانات (LocalStorage)
├── js/app.js        # منطق التطبيق والتوجيه بين الصفحات

```

## الرفع على GitHub Pages
1. أنشئ Repository جديد على GitHub وارفع محتويات مجلد `crm-pro` بالكامل.
2. من إعدادات الـ Repository: **Settings → Pages**.
3. اختر Source: **Deploy from a branch**، والفرع **main**، والمجلد **/(root)**.
4. بعد دقيقة أو اتنين هيبقى الموقع شغال على:
   `https://<username>.github.io/<repo-name>/`

## ملاحظة مهمة جدًا (لازم تعرفها) ⚠️
بما إن المشروع مستضاف على GitHub Pages وهي **استضافة ملفات ثابتة فقط بدون سيرفر خلفي أو قاعدة بيانات حقيقية**، فالنظام بيخزن البيانات في **LocalStorage الخاص بمتصفح كل جهاز على حدة**. يعني:

- لو الموظف "أحمد" فتح الموقع من لابتوبه وأضاف عميل، الإدمن مش هيشوفه على جهازه إلا لو استوردوا نفس نسخة البيانات (ملف JSON) عن طريق زرار "تصدير/استيراد" في لوحة الإدمن.
- **محادثة واتساب اللي في ملف العميل هي سجل يدوي بتكتبه إنت أو موظفينك** لتوثيق المحادثة، مش اتصال حقيقي بواتساب. الربط الفعلي مع WhatsApp Business API يحتاج سيرفر خلفي (Backend) ومفاتيح API من Meta، وده مش ممكن ينفذ من استضافة ثابتة زي GitHub Pages.

### لو عايز مزامنة حقيقية بين كل الموظفين + ربط واتساب فعلي
الخطوة الطبيعية التالية هي إضافة قاعدة بيانات سحابية مجانية زي **Firebase** أو **Supabase** (تتصل بيها من نفس ملفات الموقع عن طريق كود JavaScript بدون الحاجة لدومين خاص)، بالإضافة لسيرفر بسيط (مثلاً Cloud Function) يستقبل من WhatsApp Business API الرسمية. لو حابب، أقدر أطور النسخة دي خطوة بخطوة.

## تخصيص الشكل
كل الألوان والخطوط متجمعة في أول ملف `css/style.css` تحت `:root`، تقدر تغيّر لون العلامة التجارية `--accent` واسم الشركة من داخل `index.html`.
