# Nexus CRM — نظام إدارة علاقات العملاء (تسويق عقاري)

نظام إدارة عملاء احترافي لنشاط **التسويق العقاري**، جاهز للرفع على **GitHub Pages** بدون سيرفر أو دومين — الملفات كلها HTML + CSS + JavaScript.

## ✨ المميزات
- **تسجيل دخول بصلاحيات**: مدير (Admin) يشوف كل حاجة، وموظف يشوف عملاءه بس.
- **لوحة قيادة**: 12 مؤشر أداء لحظي، رسمان بيانيان، حلقة "نبض الفريق"، و**سجل الخطوات لحظة بلحظة** لكل إجراء يسجله الفريق.
- **قسم العقارات (التسويق العقاري)**: إضافة/تعديل/حذف العقارات، حالة كل عقار (متاح/محجوز/مباع)، وربط كل عميل بالعقار المهتم به.
- **إدارة العملاء**: إضافة/تعديل/حذف، بحث وفلترة بالحالة والموظف والعقار.
- **ملف عميل تفصيلي**: بيانات كاملة، سجل أنشطة ومتابعات (Timeline)، سجل محادثة بنمط واتساب، وزر **فتح محادثة واتساب** مباشرة.
- **التوزيع العادل التلقائي**: أي عميل جديد بدون موظف يُسند فوراً لأقل الموظفين حملاً — مع وضع "الكفاءة" لتفعيله لاحقاً (المنتج الأكثر إغلاقاً يستلم أكثر).
- **لوحة إدمن**: إدارة الموظفين، أداء الفريق، إعدادات الربط، وتصدير/استيراد نسخة احتياطية.

## 📁 هيكل المشروع
```
crm-pro/
├── index.html                  # كل الصفحات
├── lead-capture.html           # نموذج استقبال عملاء الموقع (اتصل بنا/راسلنا)
├── css/style.css               # التصميم
├── js/data.js                  # طبقة البيانات + التوزيع العادل + الربط
├── js/app.js                   # منطق التطبيق
├── INTEGRATION-GUIDE.md        # ⭐ دليل ربط كل مصدر ترافيك خطوة بخطوة
└── integration/
    ├── sheets-webhook.gs       # Webhook نموذج الموقع (Google Apps Script)
    ├── whatsapp-webhook.gs     # Webhook واتساب + ماسنجر (Meta Cloud API)
    ├── supabase.sql            # قاعدة البيانات السحابية المشتركة + التوزيع العادل
    └── supabase-edge-function.js # ويب هوك احترافي لـ Supabase
```

## 🚀 الرفع على GitHub Pages
1. ارفع محتويات مجلد `crm-pro` إلى Repository على GitHub.
2. **Settings → Pages** → Source: **Deploy from a branch** → الفرع **main** → المجلد **/root** → Save.
3. الموقع يشتغل على: `https://<username>.github.io/<repo-name>/`

## 🔌 الربط بمصادر التدفق (واتساب / ماسنجر / نموذج الموقع)
افتح **`INTEGRATION-GUIDE.md`** — دليل كامل بالعربية يشرح لكل مصدر:
- ما الذي يعمل **فوراً الآن** (نموذج الموقع عبر واتساب، التوزيع العادل، تقرير الخطوات، فتح محادثة واتساب).
- ما الذي يحتاج إعداداً من عندك (WhatsApp Business API / ماسنجر / Supabase) خطوة بخطوة مع الأكواد جاهزة.

## ⚠️ ملاحظة مهمة عن البيانات
- بدون ربط Supabase، البيانات محفوظة في **LocalStorage** لكل متصفح على حدة — انقلها بين الأجهزة بزر "تصدير/استيراد" من لوحة الإدمن.
- محادثة الواتساب داخل ملف العميل **سجل يدوي لتوثيق التواصل**، والربط الفعلي يتم عبر `integration/whatsapp-webhook.gs`.

## 🎨 تخصيص الشكل
الألوان والخطوط في بداية `css/style.css` تحت `:root` (غيّر `--accent`)، واسم الشركة من `js/data.js` أو لوحة الإدمن.
