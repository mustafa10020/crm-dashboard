# 📊 نظام CRM - لوحة التحكم

نظام إدارة علاقات عملاء احترافي باللغة العربية، يعمل بدون خادم (Serverless) 100%، ويُخزّن البيانات محلياً في المتصفح، ويمكن رفعه مجاناً على **GitHub Pages**.

## ✨ المميزات

- **لوحة تحكم** ببطاقات KPI (إجمالي العملاء، صفقات منجزة، قيد الإجراء، قيد التنفيذ، عملاء جدد، غير متواصل، متأخر، تدوير، أنشطة يومية، متابعات، تمويل، ملفات مغلقة، تعليقات اليوم)
- **تتبع دورة حياة العميل** من البداية (جديد) حتى إغلاق الملف (مغلق) مع سجل نشاط Timeline كامل
- **إدارة العملاء**: إضافة، تعديل، حذف، بحث، فلاتر (الحالة / المصدر / الموظف)
- **المتابعات**: متابعات قادمة، متأخرة، وتمت مع إتمام بنقرة واحدة
- **المهام**: مهام الفريق مع الأولويات والمواعيد
- **التقارير**: قيم الصفقات، أداء الموظفين، العملاء حسب المصدر، دورة حياة الملفات + طباعة
- **الإعدادات**: اسم الشركة، الموظفون، مصادر العملاء، نسخ احتياطي (تصدير/استيراد JSON)
- **تصميم متجاوب** RTL يعمل على الجوال والحاسوب

## 🚀 الرفع على GitHub Pages (مجاناً - بدون دومين)

الموقع يعمل كموقع ثابت تماماً، لذلك يمكنك نشره على GitHub Pages مجاناً.

### الطريقة السريعة (من الموقع فقط)

1. ادخل على [GitHub](https://github.com) وسجّل دخولك.
2. اضغط **New Repository** (مستودع جديد).
3. سمّ المستودع مثلاً: `crm-dashboard` (يمكن تركه عام Public أو خاص Private).
4. من جهازك ارفع الملفات الثلاثة: `index.html` و `style.css` و `script.js`.
5. من داخل المستودع ادخل على **Settings** ← **Pages** (من القائمة الجانبية).
6. في قسم **Branch** اختر `main` واضغط **Save**.
7. انتظر دقيقة إلى دقيقتين، ثم افتح الرابط:
   `https://<اسم_مستخدمك>.github.io/crm-dashboard/`

### الطريقة الاحترافية (سطر الأوامر)

```bash
# 1. أنشئ مستودعاً جديداً على GitHub ثم نفّذ:
git init
git add .
git commit -m "إنشاء نظام CRM"
git branch -M main
git remote add origin https://github.com/<اسم_مستخدمك>/crm-dashboard.git
git push -u origin main

# 2. من GitHub: Settings ← Pages ← Branch: main ← Save
```

## ⚠️ ملاحظة مهمة عن البيانات

- البيانات تُحفظ في **LocalStorage** داخل متصفح كل مستخدم على حدة.
- هذا يعني أن كل جهاز/متصفح لديه نسخته الخاصة من البيانات.
- عند تغيير المتصفح أو الجهاز، استخدم **تصدير البيانات** (JSON) من الإعدادات ثم **استيرادها** على الجهاز الآخر.
- لا تُمسح بيانات المتصفح (أو وضع التصفح الخاص) حتى لا تفقد بياناتك.

## 🧪 تجربة محلية

يمكنك فتح `index.html` مباشرة في المتصفح (مزدوج كليك) بدون أي خادم، وسيعمل كل شيء لأن النظام لا يحتاج خادم.

> 💡 للتحقق من عمل النظام بشكل أسرع، النظام يضيف تلقائياً بيانات تجريبية عند أول تشغيل، يمكنك مسحها من الإعدادات ← إعادة ضبط المصنع.

## 🔧 تخصيص إضافي

- **اسم الشركة والموظفون والمصادر**: من تبويب الإعدادات داخل الموقع.
- **الألوان**: عدّل المتغيرات في بداية ملف `style.css` (مثل `--primary`).
